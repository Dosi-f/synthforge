# Roadmap

## Working on
- [ ] Multi-turn conversation generation (not just single Q&A pairs)
- [ ] Automatic prompt optimization (find best template for your use case)
- [ ] Parallel generation across multiple backends
- [ ] Quality filtering with custom fine-tuned classifiers

## Want to do
- [ ] Image + text dataset generation (multimodal)
- [ ] Data augmentation pipeline (paraphrase, translate, expand)
- [ ] Integration with HuggingFace AutoTrain
- [ ] Web UI for non-coders to build generation pipelines

## Probably not
- Hosted version — keep it local, keep it free
- Support for proprietary data formats — JSONL is king

This roadmap is a rough plan, not a promise. Things change based on what I'm working on and what people actually use.
